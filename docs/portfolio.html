Controle Financeiro

Plataforma web, mobile e API REST para transformar extratos, cartões, parcelas e receitas em uma visão financeira organizada.

Web full stack

PHP, MySQL/SQLite, HTML, CSS e JavaScript com regras financeiras centralizadas.

Mobile Android

APK em Java e WebView, conectado ao mesmo domínio HTTPS sem configuração manual de URL.

API REST

API versionada, Bearer keys, escopos, rate limit, OpenAPI e Swagger UI.

Automação financeira

Importação de comprovantes, parcelas, cartões, períodos e contas futuras.

Arquitetura

Web / APK / ERP externo
          ↓ HTTPS
       API PHP REST
          ↓ PDO
    MySQL ou SQLite

O banco nunca fica exposto ao aplicativo. A API valida o usuário, aplica as regras e grava os dados.
